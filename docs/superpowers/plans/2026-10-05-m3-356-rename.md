# M3 #356: Rename the Code and Documents to Yawelo Idle

> **For agentic workers:** this plan records work already executed and gated in one commit. The code lives in that commit; the steps name the commands that built and checked it.

**Goal:** nothing the repository ships or publishes names the game by its old name, `Wordfarer`, except records of what happened and the infrastructure names #357 moves. A guard holds that from now on.

**Architecture:** `tests/unit/old-name.ts` reads every committable file and judges each occurrence of the old name, in any case, against one list of allowances (history files, history sections, quotes, infrastructure patterns). `tests/unit/old-name.test.ts` runs it over the repository and proves its own reading three ways.

**Spec:** story #356; spec D16 as amended on 2026-10-05; operator decisions on #356 (2026-10-05 10:16 and 10:18 UTC).

## Decisions this plan makes

- **Case forms (operator, 10:16 and 10:18 UTC, asked interactively):** "Yawelo Idle is the name to match everywhere, not Yawelo". Title `Yawelo Idle`, kebab `yawelo-idle` (npm scope `@yawelo-idle/*`, root package `yawelo-idle`, page stamp `yawelo-idle-commit`, cache `node_modules/.cache/yawelo-idle`), UPPER `YAWELO_IDLE_*`, camel `yaweloIdle*`.
- **Store id (operator, 10:18 UTC):** `com.shyden.yaweloidle`. Measured first from the official docs: Apple bundle ids allow A–Z, a–z, 0–9, hyphen and period (no underscore); Android application ids allow letters, digits and underscore (no hyphen). It is the only spelling of the full name valid in both. Re-securing it is #383; this story changes the text only.
- **The spec file is renamed** (operator, 10:16 UTC) to `docs/superpowers/specs/2026-10-01-yawelo-idle-design.md`; dated plans keep the old path as history. Nothing tests those paths (measured: no test or script names `specs/`).
- **Hosts** become `yawelo-idle.shyden.co.uk` with `dev.`, `api.`, `dev-api.`: #357's move, recorded on #357.
- **Where the old name stays, and why** (each an entry in `ALLOWANCES`): the clearance record `docs/compliance/trademark-search.md`; the 15 dated plans that name it, and this one; the main spec's §2 decision log and §17 review log; the content-reports spec's review log; the operator's quoted request in the website spec. The other specs' review logs name nothing, so they carry no entry.
- **Infrastructure until #357** (AC5): the hosts under `shyden.co.uk`; the Workers `wordfarer-web-dev`, `wordfarer-sync-dev` and the D1 database `wordfarer-dev`; the App `wordfarer-agent`; the repository `shyden-labs/wordfarer`; the board title "Wordfarer Stories"; the local checkouts and the memory folder keyed to them.
- **How the rename was applied:** a script outside the tree (`.superpowers/sdd/356/rename.ts`) took the guard's own findings (path, line, column) and replaced each by its case form, failing closed on any form it could not name. `HANDOVER.md` was edited by hand, because its worktree names are local paths, not the game's name. The lockfile was regenerated by `npm install`, never edited.
